# Natasha the Founder

Personal house of **Natasha Collins**, founder of [ORA Jewellery](https://orajewellery.com/), Cape Town.

This is the founder app: story, lookbook, charm-stack composer, custom brief, and studio visit. Checkout stays on Shopify at orajewellery.com.

## App

- **Story** — first piece at fifteen, Natasha G, ORA
- **Lookbook** — collections that open the Shopify store
- **Stack** — hoop or bangle, gold or silver, up to eight charms (saved on-device)
- **Custom** — six-step journey and a brief emailed to the studio
- **Studio** — appointment note
- **Members** — approved-account access to private offers, discounts, and premiere events

## Stack

React 19, TanStack Start, Tailwind v4, Zustand.

```
npm install
npm run dev
```
